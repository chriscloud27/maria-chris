# Style Guide

## Brand Direction
The visual identity is elegant, romantic, and nature-inspired.

- Elegant: serif-led typography and refined spacing
- Romantic: script accents for names and ceremonial moments
- Natural: sage/olive palette and botanical atmosphere

## Typography

### Font Families

#### Headings (Primary Display)
- Playfair Display
- Cormorant Garamond (fallback/alternative)

Use for:
- Hero headings
- Section titles
- Date/location emphasis

#### Body (Primary UI Text)
- Inter
- Nunito (fallback/alternative)

Use for:
- Paragraphs
- Navigation
- Buttons
- Form text

#### Accent (Decorative Script)
- Great Vibes
- Dancing Script (fallback/alternative)

Use for:
- Couple names
- Signature details
- Decorative text highlights

#### Mono (Utility)
- JetBrains Mono

Use for:
- Technical or utility labels only (rare in wedding-facing UI)

## Styling Principles

- Keep heading weights refined (avoid heavy, aggressive bold)
- Use script fonts sparingly for emphasis, never for long paragraphs
- Preserve generous whitespace and soft visual rhythm
- Favor olive/sage tones over saturated generic UI colors
- Maintain high readability over image backgrounds

## Components and Visual Treatment

- Background style: full-page image with graceful fallback color
- Surfaces: soft translucent white layers with subtle blur
- Borders: low-contrast mint tones
- Navigation/footer: glassmorphism-light feel with restrained shadows

## Accessibility

- Ensure text contrast remains readable over background imagery
- Avoid script font for functional UI text
- Keep body line-height around 1.6 for long-form readability
- Maintain clear focus ring visibility using sage tones

## Do / Don’t

### Do
- Use serif for structure, sans for readability, script for emotion
- Keep color hierarchy calm and natural
- Use muted tones for dividers, cards, and non-primary controls

### Don’t
- Overuse script fonts
- Introduce unrelated bright accent palettes
- Use low-contrast text on photos without overlays
- Mix too many decorative type styles in one section
