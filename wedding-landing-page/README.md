# Wedding Invitation Landing Page

This is the official wedding invitation landing page for Carolin & Sebastian.

## 📜 Features

- **Responsive Design**: Looks great on all devices, from mobile phones to desktop computers.
- **Interactive Map**: Embedded Google Maps links for easy navigation to the church and party locations.
- **Hotel Suggestions**: A curated list of nearby hotels with booking links.
- **Event Information**: Details about pre and post-wedding events.
- **Online RSVP**: A simple form to confirm attendance.
- **FAQ Section**: Answers to common questions about the wedding.

## 🚀 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) 15 (with App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) 4
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/)
- **Bundler**: [Turbopack](https://turbo.build/pack)
- **Linting**: [ESLint](https://eslint.org/)
- **Package Manager**: [npm](https://www.npmjs.com/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🛠️ Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or later)
- [npm](https://www.npmjs.com/)

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/wedding-landing-page.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd wedding-landing-page
    ```
3.  Install the dependencies:
    ```bash
    npm install
    ```

### Running the Development Server

To start the development server, run:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result. The page will auto-update as you edit the files.

## 📝 Content Management

All user-facing text and data is stored in `src/content/wedding.json`. To change any of the content on the website, simply edit this file.
